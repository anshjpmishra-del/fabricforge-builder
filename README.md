# My First Mod - Calidite

This mod adds **Calidite**, a material superior to Netherite found exclusively in The End.

## Build Instructions
1. Ensure you have Java 25 installed.
2. Use Gradle 9.5.1 to build the project.
3. Run `./gradlew build` to generate the mod jar in `build/libs`.

## Features
- Calidite Ore: Generates in The End (End Stone base).
- Rare spawn rate.
- Calidite Tools: Higher durability and damage than netherite.
